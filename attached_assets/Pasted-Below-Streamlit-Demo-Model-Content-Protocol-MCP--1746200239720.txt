Below是一套整装升级方案，把现有的 Streamlit Demo 界面改造成真正体现
Model Content Protocol (MCP) 研究能力的 专业量化分析工作台。
全部示例代码都可直接复制到 app.py 或拆分到 /pages/….

⸻

1 · 整体页面信息架构（IA）

区域	作用	Streamlit 实现要点
A. 顶部固定导航栏	LOGO + 全局导航（Data Lab / MCP Signals / Strategy / Reports / Settings）	hydralit_components.NavBar 或 streamlit-option-menu
B. 侧边浮动控制栏（动态）	日期范围、市场选择、频率、指标开关、运行按钮	st.sidebar + CSS position fixed
C. 主工作区 (Tab)	① 仪表盘② MCP 信号谱③ 策略回测&优化④ 报告中心	st.tabs([…]) or multi‑page
D. 全局消息/进度 Toast	数据加载进度、错误提示	st.toast (< v1.33) 或 st.notification
E. 页脚	版权/版本号/联系我们	自定义 HTML footer

4 · 侧边控制栏进阶

with st.sidebar:
    st.image("static/mcp_logo.png", width=140)
    st.markdown("### 数据控制面板")
    
    col1, col2 = st.columns(2)
    with col1:
        start = st.date_input("起始", value=st.session_state.get("start_date"))
    with col2:
        end   = st.date_input("结束", value=st.session_state.get("end_date"))
    
    freq = st.select_slider("频率", ["Tick", "1分钟", "5分钟", "15分钟"])
    
    markets = st.multiselect(
        "市场",
        ["AU 主力", "COMEX GC", "XAU/USD"],
        default=["AU 主力","COMEX GC","XAU/USD"]
    )
    
    factors = st.multiselect(
        "MCP 因子",
        ["MACD", "VWAP", "主动买盘占比", "盘口深度", "持仓Δ"],
        default=["MACD","VWAP"]
    )
    
    if st.button("🚀 运行分析", use_container_width=True):
        run_analysis(start, end, freq, markets, factors)

9 · MCP 能力增强点
