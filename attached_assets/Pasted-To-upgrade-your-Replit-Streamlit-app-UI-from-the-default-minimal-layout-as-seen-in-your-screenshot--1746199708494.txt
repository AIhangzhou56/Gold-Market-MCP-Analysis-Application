4. Modern Charts with Plotly or ECharts

Replace basic Matplotlib with Plotly for interactive charts:

import plotly.graph_objects as go

fig = go.Figure()
fig.add_trace(go.Candlestick(
    x=df['datetime'],
    open=df['open'],
    high=df['high'],
    low=df['low'],
    close=df['close'],
    name='K线'
))
fig.update_layout(title="沪金主力合约K线图", xaxis_rangeslider_visible=False)
st.plotly_chart(fig, use_container_width=True)

5. Signal Map Example with Color Timeline

import altair as alt

chart = alt.Chart(signal_df).mark_bar().encode(
    x='time:T',
    y=alt.value(20),
    color=alt.condition(
        alt.datum.signal == 'Buy', 
        alt.value('green'),
        alt.value('red')
    )
)
st.altair_chart(chart, use_container_width=True)
